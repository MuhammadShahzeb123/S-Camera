# OnePlus LE2121: missing telephoto button

**Update after the code 97 handset report:** the cause is now confirmed. Sensor 3 advertises normal video at up to **29 FPS**, while the old candidate list tested only 30/60 FPS. The engine therefore removed the telephoto before creating the shared profile list and zoom stops. It also lacks a 3840x2160 stream. The fix is documented in [telephoto FPS verification](telephoto-fps-verification.md); the earlier investigation below records what was known before that report arrived.

The user reports that normal Video shows no 3.3x button and zoom stops at 10x. They provided the Settings > About text for Open Camera 1.56.2, code 96, package `net.sourceforge.opencamera`, Android API 34, OnePlus LE2121. It reports five camera IDs and Camera2, with current camera ID 0, zoom 1-10x, 1920x1080 preview and 1920x1080/30 recording settings.

That text is generated by `MyPreferenceFragment` and includes only the current classic camera's capabilities. It contains neither the other cameras' FPS/stream characteristics nor the new engine's eligibility decisions and session log. It therefore does not identify the telephoto rejection or establish whether the installed APK entered the live optical pipeline. Earlier custom APKs all retained version 1.56.2/code 96, so that version string does not distinguish them.

The Video engine can remove a lens at its exact-size/FPS capability check, after inventory filtering and route discovery. Missing 3.3x is consistent with exclusion, but it could also reflect missing/misclassified inventory or entry into a different recording path. Do not call the exact capability rejection confirmed without that lens's data.

This diagnostic update makes the existing About > Copy action include every discovered sensor, route, raw preview-stream durations, the actual Video profile rejection reasons, and the pipeline log. More > Camera info uses the same report. A distinct version identifies the installed diagnostic build. The recording capability policy remains unchanged pending the phone's actual lens data.
